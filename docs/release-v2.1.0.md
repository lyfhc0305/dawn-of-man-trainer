# v2.1.0：全部工作速度倍率

从[最新 Release](https://github.com/lyfhc0305/dawn-of-man-trainer/releases/latest) 下载 `DawnOfManTrainer-v2.1.0.zip` 并完整解压。退出游戏后双击 `人类黎明修改器安装器.exe`，确认找到的游戏目录，再点击“安装 / 更新”。已装旧版的直接点“安装 / 更新”即可覆盖。

## 工作速度倍率

逐一排查了游戏的 51 种人物状态和建筑制作队列，找到 22 种带进度条的工作，全部接入倍率。效率页新增四项，原有建造速度扩大到修理与拆解，每项 1–20×：

| 项目 | 包含的工作 |
| --- | --- |
| 建造速度 | 建造、修理、拆解；建造仍需材料交付 |
| 制作速度 | 需要村民操作的全部配方：工具、武器、衣物、护甲、冶炼、木炭、皮革、布料、面粉、面包、奶酪、啤酒等 |
| 晾晒速度 | 无需村民值守的腌肉、干鱼、干皮 |
| 采集速度 | 砍伐树木、从树丛收获、地表与矿井采掘、地面拾取、捕鱼、挖土、取水 |
| 农牧速度 | 种植、耕种（人与犁同步前进）、收割、挤奶、剪毛、驯服、屠宰与宰杀 |

- 只加快进度条：原料消耗、产出数量、工具磨损和完工奖励仍按每完成一件计算。
- 烹饪、吃饭、喝水、休息等个人需要保持原速；庄稼生长、动物产奶长毛属于自然时间，不受影响。
- 只作用于玩家村民和玩家建筑，切换地图或“全部关闭”后恢复 1×。
- 游戏每帧最多完成一件，游戏速度和倍率同时开得很高时，实际提速会低于设定值。

## 界面与按键

- 效率页分为“速度”和“容量”两个标签，标签上显示各自有几项不是 1×；“全部 1×”同时恢复两个标签；每项标出最高倍率。
- Esc 不再关闭修改器，按键直接交给游戏；在面板输入框中按 Esc 只结束输入。
- F11 展开或收起面板，面板隐藏时直接打开；Shift+F11 显示或隐藏整个面板。

## 验证

- 修改器、安装器与全部检查在 macOS 上用 .NET 8 SDK 的 Roslyn 按 C# 5 规则编译；安装器对照 .NET Framework 4.8 引用程序集构建，参数与 `Build.ps1` 一致。
- 界面检查 380 项、功能与程序集检查 175 项全部通过。
- 安装器按方法签名、继承关系和唯一挂接点校验 19 个新游戏方法，任何一处不符都在写入前停止。在真实游戏原始程序集的临时副本上完成安装、校验、卸载与重装：11 个挂接入口、35 个游戏方法、39 处挂接调用，卸载后与原文件逐字节一致。真实游戏文件未改动。
- 安装器检查按 Windows 路径临时适配后在 macOS 运行，新增挂接、执行与拒绝不兼容结构的检查全部通过；依赖 Windows 文件锁和盘符路径的 13 项未在本机验证。

**尚未完成：** 安装器 EXE 没有在 Windows 上实际运行；新倍率和 Esc / F11 按键没有游戏内实测。遇到问题可在安装器中点击“卸载”恢复原文件。
