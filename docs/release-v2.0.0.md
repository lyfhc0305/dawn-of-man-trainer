# v2.0.0：停靠抽屉界面大改版

从[最新 Release](https://github.com/lyfhc0305/dawn-of-man-trainer/releases/latest) 下载 `DawnOfManTrainer-v2.0.0.zip` 并完整解压。退出游戏后双击 `人类黎明修改器安装器.exe`，确认找到的游戏目录，再点击“安装 / 更新”。源码包仍需构建。

本版只改游戏内面板，修改功能的范围与行为不变。v1.5.0 的中文图形安装器此前只在本地交付，这次随 v2.0.0 一起首次公开：自动查找游戏、单个 EXE 内含修改器与依赖、保留原文件备份、失败回滚与中断恢复。

## 界面

- 面板从屏幕中央的 1180×800 大窗口改为停靠右侧的 400×620 抽屉，位于游戏右上状态栏与右下人物卡之间，地图中央不再被遮挡。1440p 下字号与旧版相同，占屏面积约为旧版的四分之一。
- 可停靠左侧、右侧或浮动；拖动标题栏即转为浮动。可一键收起为窄栏，保留各页图标、当前速度与暂停。
- 九个标签合并为六个：常用、选中、生成（资源 / 动物 / 物资包）、世界、效率、设置；左下角“?”打开使用说明。
- 暂停与 0.25×–15× 常用速度固定在每页顶部；世界页保留对数滑块，可选 1–15 任意整数倍。
- “正在生效”列表列出属性锁、家畜保护、非 1× 的速度与倍率、已启用的快捷键，可逐项关闭。底栏的一键全部关闭需在 4 秒内点两次确认。
- 杀死含村民的单位、删除物资包和全部关闭在待确认时显示倒计时；运行时提示统一缩短，放不下时在底栏换成两行。
- 动作快捷键的启用开关与改键集中到设置页；“打开面板时暂停”移到世界页；效率页每项保留滑块与加减，去掉档位按钮。
- 改用暖炭灰配色，属性锁定使用与游戏人物卡对应的状态图标。

## 验证

- 修改器、安装器、Windows 版预览导出程序与全部检查在 macOS 上用 .NET 8 SDK 的 Roslyn 按 C# 5 规则编译；安装器对照微软官方 .NET Framework 4.8 引用程序集构建，参数与 `Build.ps1` 一致。
- 离线检查 433 项通过、0 失败：共用界面 290 项（新增跨平台 SVG 绘图后端），功能、策略与程序集 143 项。
- 安装器结构与 v1.5.0 一致：Windows 图形子系统、相同的引用程序集和四个内嵌资源；修改器对外的 11 个挂接入口签名不变。
- 安装核心在真实游戏原始程序集的临时副本上完成预检、安装、校验、重装与卸载：备份正确、重装一致、卸载完全还原；用安装后的程序集重跑 143 项检查全部通过。真实游戏文件未改动。

**尚未完成：** 安装器 EXE 没有在 Windows 上实际运行，`Build.ps1`、`Test.ps1` 与安装器测试脚本未在本轮执行；新界面没有游戏内实测。最近的游戏内实测环境仍为 Steam Dawn of Man 1.8.3 / Unity 2022.3.60f1（v1.4.0 及更早）。遇到问题可在安装器中点击“卸载”恢复原文件。

## 其他

偏好新增停靠位置与收起状态，旧偏好文件可直接读取。安装包不包含游戏原程序集、反编译游戏源码或独立游戏素材。随附 Mono.Cecil 0.11.6，许可证见 `Mono.Cecil.LICENSE.txt`；它保留有效签名的上游原版，其调试元数据中的构建路径来自上游，不是用户电脑路径。
