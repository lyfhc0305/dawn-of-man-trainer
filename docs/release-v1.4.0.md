# v1.4.0：整数效率倍率与紧凑界面

新增“效率倍率”页，四项独立调整，全部为整数、最低和默认均为1倍：

- 仓储容量：1–10倍，仅玩家已建成封闭仓储，不改露天堆场。
- 建造速度：1–20倍，提高正常施工进度，材料交付与原生完工奖励照常。
- 人力搬运：1–10倍，提高成年及老年村民的普通货物容量；儿童、重物和专用装备槽保留原规则。
- 拖板与拖车容量：1–10倍，保留原生牵引和装卸规则。

每项都有整数吸附滑块、加减和快捷档位。倍率卡片高度减少24%，该页窗口高度减少20%，保留字号。降低容量保留已有物品，超容量槽位拒绝追加且仍可卸出。切换地图或“关闭所有开关”时四项恢复1倍，倍率不写入偏好。

同时合入窗口边缘定位、暂停恢复、待销毁目标过滤、危险操作确认、物资包数量边界和安装器事务恢复等修复。

## 下载与安装

下载本页附件 **DawnOfManTrainer-v1.4.0.zip**，解压后退出游戏，运行其中的 `安装.cmd`。游戏不在默认D盘Steam目录时，可在解压目录运行：

```powershell
.\Installer.exe "你的 DawnOfMan 游戏目录"
```

进入地图按 **F11 → 效率倍率**。卸载前退出游戏，再运行 `卸载.cmd`。

安装包含预编译修改器、安装器、Mono.Cecil及其许可证、源码、检查脚本和说明。无需.NET SDK；需要Windows的.NET Framework 4.x及本机已安装的适配游戏。不包含游戏程序集、游戏资源、个人存档或偏好。GitHub自动生成的Source code压缩包只含源码，需先自行构建。
