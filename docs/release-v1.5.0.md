# v1.5.0：中文图形安装器与新手说明

本次为本地 v1.5.0 交付，未发布到 GitHub Release。完整解压 `DawnOfManTrainer-v1.5.0.zip`，或使用交付文件夹中的安装器和说明。退出游戏后双击 `人类黎明修改器安装器.exe`，确认找到的游戏目录，再点击“安装 / 更新”。修改器与 Mono.Cecil 已包含在安装器中，无需运行 cmd，也无需把安装包放到游戏旁边。

安装窗口会在后台查找 Steam 游戏库、注册表、程序附近和常见盘符下的游戏位置。找不到时自动弹出文件夹选择；也可点击“浏览…”或“重新查找”。手动选择的游戏主文件夹应同时包含 `DawnOfMan.exe` 和 `DawnOfMan_Data\Managed\Assembly-CSharp.dll`。

窗口提供“安装 / 更新”、验证安装、卸载、打开游戏目录与使用说明。沿用原始程序集校验、原文件备份、失败回滚和中断恢复；发现未知文件改动时停止处理。旧命令行方式继续接受显式游戏路径及 `--verify`、`--uninstall` 参数。

安装成功后，照常启动游戏并进入地图，按 **F11** 打开 / 隐藏修改器，**Esc** 关闭。新手步骤、常用功能、存档影响、卸载与故障处理见安装包内的 `使用说明.txt`，仓库副本见[详细说明](使用说明.txt)。

游戏功能沿用 v1.4.0：仓储 1–10×、建造 1–20×、成年与老年村民普通搬运 1–10×、拖板与拖车 1–10×，全部为整数，最低和默认均为 1×。切换地图或关闭所有开关会重置倍率。已保存的资源、建造和死亡等实际结果，不会因卸载而撤销。

本版共通过 589 项检查、0 失败（功能与程序集 133、游戏面板离线界面 218、安装事务 154、目录查找 43、单 EXE 交付 30、图形交互 11）。单个 EXE 已在中文路径下完成安装、重复更新、验证及卸载，卸载恢复原文件；默认与 125% 模拟缩放布局已核查。全部安装测试使用临时游戏副本，真实游戏文件未改动，本轮未启动游戏。最近的游戏内实测环境仍为 Steam Dawn of Man 1.8.3 / Unity 2022.3.60f1；安装器按原始程序集哈希校验支持范围，不表示所有游戏版本均已验证。

历史验证分别见 [v1.4.1 路径验证](1.4.1路径验证结果.txt)与 [v1.4.0 倍率验证](1.4.0倍率验证结果.txt)。v1.4.1 的 505 项离线检查、v1.4.0 的 600 项检查（含 112 项游戏内自检）均为历史记录，不作为本版重跑结果。历史地图未保存，长期自然 AI 搬运、超原容量物品完整存读档循环与复杂旧档兼容仍未完成全面验收。

安装包不包含游戏原程序集、反编译游戏源码或独立游戏素材。随附 Mono.Cecil 0.11.6，许可证见根目录 `Mono.Cecil.LICENSE.txt`。
