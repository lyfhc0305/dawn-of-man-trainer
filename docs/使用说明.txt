《人类黎明》内置修改器 1.4.0
当前适配本机 Steam Dawn of Man 1.8.3；安装器按原始程序集哈希校验。

使用与导航
进入地图后按 F11 显示 / 隐藏面板，Esc 关闭。
九个标签：基础功能、选中目标、添加资源、产生动物、物资包、世界控制、效率倍率、偏好设置、使用说明。
面板打开时可直接在面板外点选目标，再在面板中执行；支持多选。
状态预览、按钮数量和实际操作会统一排除已销毁、待销毁的目标。
面板大小按分辨率自动适配，可在偏好设置调整；顶部空白区域可拖动。拖到屏幕边缘时停在边缘，不会跳回屏幕中央。鼠标在面板上或正在输入时拦截原游戏操作，面板外照常操作游戏。

基础功能
七项属性锁：健康、饱食、口渴、温度、体力、休息、精神；默认只保护玩家人物，可额外保护家畜。
属性行可点击切换。每次启动，属性锁和操作快捷键开关默认关闭。
健康锁仅保持健康值，不阻止寿命结束、雷击等直接死亡。
知识提供 +10 / +100 / +1000；添加结果会随存档保存。
“选中目标”卡片汇总可救助、可驯化、可杀死、未完工建筑和可修缮的数量，点“前往选中目标”执行操作。
默认 Ins / Del / F10 分别为快速建造 / 杀死单位 / 重复添加资源；前两个开关在选中目标页，F10 开关在资源页，需先启用。
操作快捷键只在面板关闭、正常地图交互、没有菜单或模态窗口、没有输入焦点时生效，修饰组合键不触发。
处理后的动作按键会拦截原游戏同帧输入。F8 保留给原游戏家畜面板。

选中目标 — 人物与动物
显示所选存活玩家人物和家畜的平均生存状态。
杀死单位可处理选中存活人物或动物；此类结果会随存档保存。
选中目标含玩家村民时，按钮需再次点击确认，快捷键需在 4 秒内再按一次。
切换目标、切换页面或显示 / 隐藏面板时，杀死单位的待确认操作失效；切回原目标也须重新确认。进入原生菜单等快捷键不可用状态时，也会清除快捷键的待确认操作。
“恢复健康”是一次性补满健康值；“补满生存状态”补满各单位实际具有的属性。
不复活、不清除疾病、不修改年龄，也不恢复敌人或野生动物。
快速驯化只处理符合游戏原生捕捉条件的动物：自然阵营、幼年、科技已解锁、对应家畜存在，且没有正在执行的任务。
转换沿用原生家畜品种转换和新增家畜通知；保持原生生成行为，不保证复制旧动物的具体健康和岁数。

选中目标 — 建造与维护
快速建造可无材料完成选中玩家建造目标，并沿用原生建造计数和知识奖励，重复完成不重复发奖。
按未完工、未回收的玩家建造目标显示尚未交付材料。
补给时重新计算清单，按各建筑位置在附近地面分批生成，仍由村民搬运、正常施工。
清单不扣除仓库、地面、居民携带和运输途中的材料，重复补给可能额外生成。
不会直接改写建筑的内部缺料清单，不会取消或回收建造任务。
修缮建筑仅处理选中且已建成、未回收、未待销毁的玩家建筑，恢复状态并更新模型。
工具 / 衣物耐久仅恢复直接选中的资源物品，不自动遍历库存或人物装备；自然磨损之后继续发生。

添加资源
当前目录读取到 87 种资源；支持按当前游戏语言下的资源名称 / 英文 ID 搜索，以及类别和收藏筛选。
选择卡片，在右侧输入 1–1000 件，也可加减或使用快选数量。
选择“目标附近 / 画面中心”；没有选中目标时明确回退到画面中心地面。
物品在地面生成，由村民搬运入库。按钮标明实际物品与数量。
筛选不会自动更换已选物品；已选项在筛选结果外时有明确提示。
点击“收藏”保留常用资源；“加入物资包「名称」”加入物资包页当前选中的清单，按钮上显示清单名称。
生成中显示实际任务和进度，完成后短暂显示绿色确认。
顶部“停止后续生成”仅停止尚未生成的部分，已生成、搬运或消耗的物品不会撤回。
开启快捷添加后，隐藏面板按对应按键重复添加最近选定物品和数量。

产生动物
当前目录读取到 31 种动物，每次 1–50 只；支持年龄、性别、两种生成位置。
物种保留原有阵营，野生动物不会因为生成而自动驯化。
资源和动物分别记住搜索，点击当前标签不清空筛选；清空搜索后回到顶部。

物资包
预置“建村材料”“过冬补给”，可以修改名称、数量、移除项目，或新建、删除清单（删除需再次点击确认）。
可在本页直接搜索物品，点击结果加入 10 件；也可从资源页加入。
重复加入会累加当前行；超过单项 1000 件时提示并保留原值。当前行为空白、非数字或不大于 0 时，点击搜索结果的 +10 可把该行恢复为 10。
可在此查看每项数量、种类数与总数，再整包生成；数量无效的行会标红，底部用红字说明问题。
每项 1–1000 件；每包最多 64 种资源、一次最多 5000 件；最多保存 16 个物资包。
执行时先复制并完整校验清单，有无效数量或不存在物品时整包不进入队列。
运行中编辑清单不会改变已排定任务。可以停止后续生成，已生成部分保留。
缺料补给和普通资源 / 动物生成共用任务队列，同一时间只执行一批。

世界控制
0.25× / 0.5× 慢速和 1–15× 速度，支持暂停、继续。
速度滑条按倍数均匀分布（0.25×–1× 与 1×–4× 等宽）；面板自动暂停时会显示关闭面板后恢复的倍率。
修改器暂停会记住暂停前实际倍率，包括原游戏设定的 8× 等速度。
五种天气：晴朗、降雨、降雪、雷暴、暴风雪；按原生规则渐变，不跳过季节，后续自然变化。
邀请移民检查住房余量及在途移民；邀请商人检查现存商人。
均调用原生来访流程，移民批次和年龄 / 性别由场景决定，从地图边缘前来，不保证立刻加入。
修改器不重置自然来访计时器，游戏自身仍可能另外生成自然访客。

效率倍率
新增第九个标签“效率倍率”，四项倍率独立设置：仓储容量 1–10×、施工效率 1–20×、人力搬运 1–10×、拖板 / 拖车运力 1–10×。
支持滑块、加减和常用档位；滑块按整数吸附，加减每次调整 1×。全部为整数，最低和默认值均为 1×；切换地图或点击“关闭所有开关”时全部恢复 1×，不保存到偏好。
仓储只提高已建成玩家封闭仓储建筑的货物槽容量，范围为原生带 Storage 标记且不带 VisibleStorage 标记的建筑；露天堆放场不改变。
人力搬运只提高玩家成年和老年村民的普通货物容量；儿童、重物搬运与专用工具 / 衣物装备槽仍按原游戏规则处理。
拖板 / 拖车只提高已建成玩家拖板和拖车的普通货物容量。
运力按原生同类货物槽的容量提高，不增加槽位数量；实际一趟搬运数量还会受到混装和搜集路径影响。
降低倍率不会删除已存放或携带的实物；超过新容量的槽位会拒绝继续装入，现有物品仍可卸出。
施工效率提高玩家村民对玩家建筑的正常施工进度；仍需正常交付材料，并沿用原生施工、完工与知识奖励流程。

偏好设置
点击操作对应按键按钮，再按新键；Esc 取消录入。
自定义单键检查原游戏主 / 副键绑定、修改器重复键与硬保留键；发生冲突会提示换键。
默认 Ins / Del 的接管规则保留：仅对应开关开启、正常交互时由修改器消费输入。
F11 显隐和 Esc 关闭固定保留；不支持修饰组合键、鼠标或手柄键作为操作快捷键。
自动暂停默认关闭，可以开启。打开面板时记录并暂停，关闭时恢复原倍率。
原来已暂停且不操作时不会自动继续；面板内显式选择新速度会继续保持暂停，关闭后才应用新倍率。
不会通过 unpause 解开游戏菜单的真实暂停；切换地图时清理暂停所有权。
面板打开时用原游戏按键改了速度，以该速度为准，关闭面板后不再改回。
界面大小 100% 按分辨率自动适配（约占屏幕高度 3/4），可选 80%–150%，始终不超出屏幕。
自动保存收藏、物资包、数量、已选物品 / 动物、窗口位置、按键、界面大小和自动暂停偏好。
不保存属性锁、杀死单位等功能的启用状态，也不保存四项效率倍率。“恢复默认键位与界面偏好”重置按键、自动暂停和界面大小，不会删除收藏和物资包。
偏好文件位于：游戏目录\DawnTrainer\preferences.ini；与原游戏存档分开。
“关闭所有开关”停止持续修改、取消未完成生成，将四项效率倍率恢复为 1×，并将游戏恢复速度设为 1×。面板自动暂停开启时，1× 在关闭面板后恢复。
原生游戏菜单暂停时不会强行解开菜单暂停；退出菜单后再应用 1×，若面板仍处于自动暂停，则继续等到关闭面板。

安装与卸载
安装完成后，平时直接启动游戏即可。
以后重新安装：退出游戏，双击“安装.cmd”。卸载：退出游戏，双击“卸载.cmd”。
更换路径时：Installer.exe "新的 DawnOfMan 游戏目录"
卸载：Installer.exe --uninstall "新的 DawnOfMan 游戏目录"
校验：Installer.exe --verify
原文件备份：游戏目录\DawnTrainer\Assembly-CSharp.dll.original
安装器仅接受明确支持的原始程序集，校验当前挂接文件、清单及备份后才更新或还原。
安装与卸载会保留事务恢复记录，统一处理游戏挂接程序集、修改器功能库和安装清单；普通异常会回滚本轮变更。
若安装器意外退出，重新运行安装或卸载会先恢复未完成事务，再执行本次操作；校验命令只读，发现待恢复事务时会停止并提示。
恢复时发现文件被其他程序改动或恢复快照损坏，会保留事务并停止；不会覆盖未知文件。多文件并非一次原子提交，中断后应先完成恢复再启动游戏。
Steam 更新或验证完整性可能恢复原文件，需要重新安装；新版游戏可能需要重新适配。
卸载保留原文件备份与个人偏好，不删除游戏存档。
