### 效率倍率

四项均支持整数吸附滑块、每次增减 1× 和常用档位按钮，**最低与默认值均为 1×**。

| 项目 | 范围 | 生效范围 |
| --- | --- | --- |
| 仓储容量 | 1–10× | 已建成的玩家封闭储藏建筑；排除露天可见堆场 |
| 建造速度 | 1–20× | 玩家村民对玩家建筑的正常施工进度；材料交付与搬运照常，保留原生完工及知识奖励 |
| 人力搬运 | 1–10× | 玩家成年、老年村民的普通货物容量；儿童、重物及专用工具、衣物装备槽保持原规则 |
| 运输工具容量 | 1–10× | 已建成的玩家拖板与拖车；犁和巨岩运输方式保持原规则 |

容量倍率扩大同类货物槽的容量，不增加槽位数量；实际一趟运量还受混装、收集范围和派工影响。降低倍率会保留已有物品，超额槽位允许卸出、拒绝继续装入。倍率不保存到偏好，切换地图或点击“关闭所有开关”均恢复 1×；未进入地图时无法调整。

## 安装与使用

1. 完整解压本地交付的 `DawnOfManTrainer-v1.5.0.zip`；也可直接使用交付文件夹中的安装器和说明。
2. **完全退出游戏**，双击 `人类黎明修改器安装器.exe`。安装器会在后台查找 Steam 游戏库、注册表、程序附近和常见盘符下的游戏位置。
3. 确认找到的是要安装的游戏；未找到时会弹出文件夹选择窗口，也可点击“浏览…”手动选择或“重新查找”。应选择同时包含 `DawnOfMan.exe` 和 `DawnOfMan_Data\Managed\Assembly-CSharp.dll` 的**游戏主文件夹**。可在 Steam 库中右键游戏 → 管理 → 浏览本地文件查看位置。
4. 点击“安装 / 更新”，等待成功提示。可点击“验证安装”检查结果；“打开游戏目录”和“使用说明”可直接打开对应内容。
5. 照常启动游戏并进入地图，按 **F11** 打开 / 隐藏面板，**Esc** 关闭。面板打开时，可以直接在**面板外的地图上点选目标**，再在“选中目标”页操作；支持多选。

安装器已内含修改器与 Mono.Cecil，安装包可放在任意位置，无需命令行。电脑有多份游戏时，请手动选择需要安装的那一份。

默认 **Ins / Del / F10** 分别对应快速完成建造、杀死选中单位、重复添加资源，需先在对应页面启用开关。动作快捷键只在面板关闭、正常地图交互且没有菜单或输入焦点时生效；F8 保留给原游戏家畜面板。持续修改与动作快捷键开关每次启动默认关闭。

安装器校验游戏程序集、保留原始备份，并提供失败回滚和中断恢复。遇到未完成事务时，重新运行安装或卸载完成恢复后再启动游戏。**卸载时先退出游戏，再打开安装器，确认游戏目录后点击“卸载”**。卸载保留备份、个人偏好与游戏存档；Steam 更新或验证游戏文件后可能需要重新安装。

旧命令行方式继续兼容显式参数：`Installer.exe "游戏目录"`、`Installer.exe --verify "游戏目录"`、`Installer.exe --uninstall "游戏目录"`。相对游戏路径以安装器所在目录为起点，与终端当前目录无关。

资源在地图地面生成，仍由村民搬运；建筑缺料补给仍需村民交付和施工。健康锁不会拦截寿命结束、雷击等直接死亡机制。选中村民执行杀死操作需要再次确认；添加物品、建造和死亡等实际修改结果会随用户存档保存，关闭开关或卸载不会撤销已保存的修改。第一次使用前建议另存一份原存档。

自动查找失败、F11 无反应、快捷键和权限等常见问题见[新手使用说明](使用说明.txt)。

## 从源码构建

从仓库克隆或使用 **Code → Download ZIP** 获取源码。需要 Windows 自带 .NET Framework C# 编译器，以及本机已安装的适配游戏；**不需要 .NET SDK**。

在源码根目录的 PowerShell 中运行：

```powershell
.\Build.ps1 -GamePath '..\DawnOfMan'
.\Test.ps1 -GamePath '..\DawnOfMan'
.\TestInstaller.ps1
.\TestDiscovery.ps1
.\TestSetup.ps1 -GamePath '..\DawnOfMan'
.\TestInstallerUi.ps1 -GamePath '..\DawnOfMan' -CheckEnvironmentDiscovery
.\Package.ps1
```

`Build.ps1` 和 `Test.ps1` 默认使用 `..\DawnOfMan`。默认或显式传入的相对 `-GamePath` 都以各自**脚本所在目录**为起点，与终端当前目录无关；也接受绝对路径。

构建生成 `DawnOfManTrainer.dll` 和 `Installer.exe`；图形安装器内嵌所需功能库与依赖。`Test.ps1` 运行核心与界面离线检查，`TestInstaller.ps1` 在独立临时目录验证安装器事务；所有检查均不启动游戏，也不对真实游戏执行安装。`TestDiscovery.ps1` 检查目录发现，`TestSetup.ps1` 检查单 EXE 交付，`TestInstallerUi.ps1` 检查窗口状态和异步验证；`-CheckEnvironmentDiscovery` 额外确认本机可自动找到给定游戏。`Package.ps1` 将中文 EXE、说明和许可证打包到 `release\v1.5.0`。

游戏内诊断仅在显式指定 `--trainer-self-test` 时执行，普通启动不会执行测试或抑制自动存档。

```text
src/TrainerMultipliers.cs             仓储、施工、人力与运输工具倍率接入
src/IntegrationMultiplierChecks.cs    倍率功能的真实地图状态自检
src/                                 其他修改器逻辑、共用界面、Unity 绘制、安装器和诊断
tests/                               策略、程序集、安装器、界面检查及离线预览导出
docs/                                说明、当前及历史验证日志、预览与历史游戏截图
Build.ps1                            构建修改器与安装器
Test.ps1                             核心与界面离线验证
TestInstaller.ps1                    独立安装器事务与挂接验证
```

构建时引用本机游戏程序集。仓库和 Release 安装包均不包含游戏原程序集、反编译游戏源码或独立游戏素材。随附第三方依赖 Mono.Cecil 0.11.6，其许可证见 [Mono.Cecil.LICENSE.txt](Mono.Cecil.LICENSE.txt)。
