# 人类黎明内置修改器 · Dawn of Man Trainer

在游戏内按 **F11** 打开控制台，管理人物状态、资源、动物、建筑与世界。面板停靠在屏幕右侧，不挡住地图中央，可收起为窄栏或拖成浮动窗口。

**当前版本：v2.0.0（界面大改版）** · 最近游戏内实测环境：本机 Steam **Dawn of Man 1.8.3 / Unity 2022.3.60f1 / Windows**（v1.4.0 及更早版本）。安装器按原始游戏程序集哈希校验支持范围；这不代表已验证所有游戏版本。

**[下载最新 Release 安装包](https://github.com/lyfhc0305/dawn-of-man-trainer/releases/latest)**，选择 `DawnOfManTrainer-v2.0.0.zip`，完整解压后双击 `人类黎明修改器安装器.exe`。仓库的 **Code → Download ZIP** 是源码包，使用前需要构建。

## 功能

| 页面 | 功能 |
| --- | --- |
| 每页顶部 | 暂停与 0.25×–15× 常用速度；底栏显示生效的修改数量，可一键全部关闭（4 秒内点两次确认）或停止后续生成；放不下的提示换成两行 |
| 常用 | 七项人物属性锁与“全部”方块、同时保护家畜开关、知识点、正在生效的修改列表（可逐项关闭） |
| 选中 | 单位：平均生存状态、一次性恢复健康与属性、符合原生条件的幼年动物驯化、杀死选中单位；建筑与物品：缺料补给、快速完成建造、修缮建筑、工具及衣物耐久 |
| 生成 | 资源：真实游戏目录、名称或英文 ID 搜索、分类、收藏；动物：物种、年龄、性别；物资包：保存与编辑多种资源清单、先完整校验再按快照执行。底部固定数量、位置与添加按钮 |
| 世界 | 1–15 任意整数倍的对数滑块、五种天气、原生流程邀请移民和商人、打开面板时自动暂停 |
| 效率 | 仓储容量、建造速度、人力搬运、拖板与拖车容量四项独立整数倍率 |
| 设置 | 三个动作快捷键的启用与改键、游戏键位冲突检查、停靠位置、界面大小；收藏、物资包等偏好自动保存 |
| 使用说明 | 左下角“?”打开：快捷键、添加资源步骤与使用提示 |

### 效率倍率

四项均支持整数吸附滑块和每次增减 1× 的按钮，滑块两端标出范围，**最低与默认值均为 1×**。

| 项目 | 范围 | 生效范围 |
| --- | --- | --- |
| 仓储容量 | 1–10× | 已建成的玩家封闭储藏建筑；排除露天可见堆场 |
| 建造速度 | 1–20× | 玩家村民对玩家建筑的正常施工进度；材料交付与搬运照常，保留原生完工及知识奖励 |
| 人力搬运 | 1–10× | 玩家成年、老年村民的普通货物容量；儿童、重物及专用工具、衣物装备槽保持原规则 |
| 运输工具容量 | 1–10× | 已建成的玩家拖板与拖车；犁和巨岩运输方式保持原规则 |

容量倍率扩大同类货物槽的容量，不增加槽位数量；实际一趟运量还受混装、收集范围和派工影响。降低倍率会保留已有物品，超额槽位允许卸出、拒绝继续装入。倍率不保存到偏好，切换地图或点击“关闭所有开关”均恢复 1×；未进入地图时无法调整。

## 安装与使用

1. 从 [Releases](https://github.com/lyfhc0305/dawn-of-man-trainer/releases/latest) 下载并完整解压 `DawnOfManTrainer-v2.0.0.zip`，包内有安装器、使用说明和第三方许可证。
2. **完全退出游戏**，双击 `人类黎明修改器安装器.exe`。安装器会在后台查找 Steam 游戏库、注册表、程序附近和常见盘符下的游戏位置。
3. 确认找到的是要安装的游戏；未找到时会弹出文件夹选择窗口，也可点击“浏览…”手动选择或“重新查找”。应选择同时包含 `DawnOfMan.exe` 和 `DawnOfMan_Data\Managed\Assembly-CSharp.dll` 的**游戏主文件夹**。可在 Steam 库中右键游戏 → 管理 → 浏览本地文件查看位置。
4. 点击“安装 / 更新”，等待成功提示。可点击“验证安装”检查结果；“打开游戏目录”和“使用说明”可直接打开对应内容。
5. 照常启动游戏并进入地图，按 **F11** 打开 / 隐藏面板，**Esc** 关闭。面板默认停靠在屏幕右侧；打开时可以直接在**面板外的地图上点选目标**，再在“选中”页操作，支持多选。标题栏右侧按钮把面板收起成窄栏；拖动标题栏可让面板浮动，在“设置”页重新停靠。

安装器已内含修改器与 Mono.Cecil，安装包可放在任意位置，无需命令行。电脑有多份游戏时，请手动选择需要安装的那一份。

默认 **Ins / Del / F10** 分别对应快速完成建造、杀死选中单位、重复添加资源，需先在“设置”页启用开关。动作快捷键只在面板关闭、正常地图交互且没有菜单或输入焦点时生效；F8 保留给原游戏家畜面板。持续修改与动作快捷键开关每次启动默认关闭。

安装器校验游戏程序集、保留原始备份，并提供失败回滚和中断恢复。遇到未完成事务时，重新运行安装或卸载完成恢复后再启动游戏。**卸载时先退出游戏，再打开安装器，确认游戏目录后点击“卸载”**。卸载保留备份、个人偏好与游戏存档；Steam 更新或验证游戏文件后可能需要重新安装。

旧命令行方式继续兼容显式参数：`Installer.exe "游戏目录"`、`Installer.exe --verify "游戏目录"`、`Installer.exe --uninstall "游戏目录"`。相对游戏路径以安装器所在目录为起点，与终端当前目录无关。

资源在地图地面生成，仍由村民搬运；建筑缺料补给仍需村民交付和施工。健康锁不会拦截寿命结束、雷击等直接死亡机制。选中村民执行杀死操作需要再次确认；添加物品、建造和死亡等实际修改结果会随用户存档保存，关闭开关或卸载不会撤销已保存的修改。第一次使用前建议另存一份原存档。

自动查找失败、F11 无反应、快捷键和权限等常见问题见[新手使用说明](使用说明.txt)。

## 从源码构建

从仓库克隆或使用 **Code → Download ZIP** 获取源码。需要 Windows 自带 .NET Framework C# 编译器，以及本机已安装的适配游戏；**不需要 .NET SDK**。

在源码根目录的 PowerShell 中运行：

```powershell
.\Build.ps1 -GamePath '..\DawnOfMan'
.\Test.ps1 -GamePath '..\DawnOfMan'
.\TestInstaller.ps1
.\TestDiscovery.ps1
.\TestSetup.ps1 -GamePath '..\DawnOfMan'
.\TestInstallerUi.ps1 -GamePath '..\DawnOfMan' -CheckEnvironmentDiscovery
.\Package.ps1
```

`Build.ps1` 和 `Test.ps1` 默认使用 `..\DawnOfMan`。默认或显式传入的相对 `-GamePath` 都以各自**脚本所在目录**为起点，与终端当前目录无关；也接受绝对路径。

构建生成 `DawnOfManTrainer.dll` 和 `Installer.exe`；图形安装器内嵌所需功能库与依赖。`Test.ps1` 运行核心与界面离线检查，`TestInstaller.ps1` 在独立临时目录验证安装器事务；所有检查均不启动游戏，也不对真实游戏执行安装。`TestDiscovery.ps1` 检查目录发现，`TestSetup.ps1` 检查单 EXE 交付，`TestInstallerUi.ps1` 检查窗口状态和异步验证；`-CheckEnvironmentDiscovery` 额外确认本机可自动找到给定游戏。`Package.ps1` 将中文 EXE、说明和许可证打包到 `release\v2.0.0`（`DawnOfManTrainer-v2.0.0.zip`）。界面检查分为共享检查 `tests/UiChecks.cs` 与两个绘图后端：`tests/UiPreview.cs`（Windows，导出 PNG，由 `Test.ps1` 运行）和 `tests/UiSvgPreview.cs`（跨平台，导出 SVG，可在 macOS / Linux 用 .NET SDK 运行）。

游戏内诊断仅在显式指定 `--trainer-self-test` 时执行，普通启动不会执行测试或抑制自动存档。

```text
src/TrainerMultipliers.cs             仓储、施工、人力与运输工具倍率接入
src/IntegrationMultiplierChecks.cs    倍率功能的真实地图状态自检
src/                                 其他修改器逻辑、共用界面、Unity 绘制、安装器和诊断
tests/                               策略、程序集、安装器、界面检查及离线预览导出
docs/                                说明、当前及历史验证日志、预览与历史游戏截图
Build.ps1                            构建修改器与安装器
Test.ps1                             核心与界面离线验证
TestInstaller.ps1                    独立安装器事务与挂接验证
```

构建时引用本机游戏程序集。仓库和 Release 安装包均不包含游戏原程序集、反编译游戏源码或独立游戏素材。随附第三方依赖 Mono.Cecil 0.11.6，其许可证见 [Mono.Cecil.LICENSE.txt](Mono.Cecil.LICENSE.txt)。
